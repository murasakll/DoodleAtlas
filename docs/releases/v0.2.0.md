# DoodleAtlas v0.2.0 — primeiro pacote para download / first downloadable package

**Prévia / Pre-release — Windows x64**

## Português

Um caderno de mapas para Minecraft Bedrock, com terreno observado, jogadores ao vivo e ferramentas para desenhar suas próprias anotações.

### Downloads

- **DoodleAtlas-v0.2.0-windows-x64.zip**: aplicativo, interface, recursos, documentação e instalador. Não precisa de Git.
- **DoodleAtlas-Universal-v0.2.0.mcpack**: pack universal para importar no Minecraft; também pode ser gerado pelo instalador.
- **SHA256SUMS.txt**: hashes para conferir os downloads.

### Como começar

1. Baixe o ZIP do aplicativo e extraia a pasta inteira em um lugar seu.
2. Execute `instalar.bat`. É necessário acesso à internet para baixar Python 3.12 e dependências.
3. Execute `iniciar.bat` e abra o endereço mostrado no terminal.
4. Se houver vários saves, escolha o caminho do mundo em `config/settings.local.json` ou use `python -m chiko serve --world CAMINHO`, com o Python instalado pelo projeto quando necessário.
5. Para jogadores ao vivo, importe o `.mcpack`, ative-o no mundo, habilite o Content Log e execute o comando de vínculo mostrado em Ajustes → Leitura e captura do jogo.

O instalador não inclui nem altera seu mundo original e não muda regras de Firewall. O pacote não contém mundos, dados pessoais, configurações locais, suíte de testes ou uma instalação pronta do Python. O download do pack sozinho não substitui o aplicativo no PC.

### Funções desta versão

- Interface doodle com temas claro/escuro/sistema, sketch e sons opcionais.
- Português e inglês, com escolha salva no navegador.
- Terreno em estilo Atlas ou cores naturais, Overworld/Nether/End.
- Dados do save, captura pelo pack e jogadores ao vivo quando o jogo fornece os dados.
- Editor com carimbos, conexões automáticas, fundo pintado e construção modular.
- Pontos pessoais/compartilhados, histórico por região e exportação PNG/JSON.
- Prévia opcional e experimental de biomas pela seed no Overworld compatível.

### Limites

O pack declara engine mínima 1.26.50 e Script API 2.9.0. A prévia de seed tem restrições próprias de versão. Não há garantia para versões futuras, integração automática com qualquer Realm/servidor público ou ganho de FPS. A instalação em outros PCs e o uso prolongado ainda precisam de validação; por isso esta versão é uma prévia.

Ao atualizar, preserve seus dados e configurações. Não extraia sobre uma instalação em execução. Consulte o guia de backup para bancos SQLite abertos e pontos locais do navegador.

## English

A map notebook for Minecraft Bedrock, with observed terrain, live players and tools for drawing your own annotations.

### Downloads

- **DoodleAtlas-v0.2.0-windows-x64.zip**: application, interface, assets, documentation and installer. Git is not required.
- **DoodleAtlas-Universal-v0.2.0.mcpack**: universal pack to import into Minecraft; the installer can also generate it.
- **SHA256SUMS.txt**: checksums to verify downloads.

### Get started

1. Download the application ZIP and extract the entire folder.
2. Run `instalar.bat`. Internet access is required to download Python 3.12 and dependencies.
3. Run `iniciar.bat` and open the address shown in the terminal.
4. If you have several saves, set the world path in `config/settings.local.json` or use `python -m chiko serve --world PATH`, with the project's Python executable when needed.
5. For live players, import the `.mcpack`, enable it in the world, enable the Content Log and run the linking command shown under Settings → Game reading and capture.

The installer does not modify your original world or Firewall rules. The package excludes worlds, personal data, local settings, the test suite and a ready-made Python installation. The pack alone does not replace the desktop application.

### Included

Doodle interface, light/dark/system themes, optional sketch animation and sounds, Portuguese/English, Atlas/natural terrain styles, three dimensions, save reading, live pack data, manual cartography and modular building, personal/shared places, regional history, PNG/JSON export and an optional experimental seed biome preview.

### Limits

The pack declares minimum engine 1.26.50 and Script API 2.9.0. Seed previews have their own version restrictions. Future versions, automatic access to every Realm/public server and FPS improvements are not guaranteed. Installation on other PCs and long sessions still need validation; this is a pre-release.

Preserve your data and settings before updating. Do not extract over a running installation. See the backup guide for open SQLite databases and browser-local places.
